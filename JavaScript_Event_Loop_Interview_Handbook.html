What is the Event Loop?

JavaScript can execute only one task at a time. The Event Loop checks whether the Call Stack is empty and decides which queued task should run next.

Call Stack Empty? │ ├── No → Wait │ └── Yes │ ▼ Move Microtask │ ▼ Move Macrotask

Call Stack

The Call Stack stores the currently executing functions.

function one(){ two(); }
function two(){ console.log("Hello"); }
one();
Top two() one() Global

Callback Queue (Macrotask Queue)

Tasks from setTimeout, setInterval and DOM events wait here until the Call Stack becomes empty.

setTimeout() │ ▼ Macrotask Queue │ ▼ Call Stack

Microtask Queue (Promise Queue)

Promises, queueMicrotask() and MutationObserver are placed here.

Microtasks always run before Macrotasks.

Promise.then() │ ▼ Microtask Queue │ ▼ Call Stack

Promise Queue vs Macrotask Queue

Microtask QueueMacrotask Queue
Promise.then()setTimeout()
queueMicrotask()setInterval()
Runs FirstRuns After Microtasks

Interview Example

console.log(1);

setTimeout(()=>console.log(2));

Promise.resolve().then(()=>console.log(3));

console.log(4);

Step-by-Step

1. console.log(1) → Output 1 2. setTimeout() ↓ Macrotask Queue 3. Promise.then() ↓ Microtask Queue 4. console.log(4) → Output 4 5. Call Stack Empty 6. Run Microtask → 3 7. Run Macrotask → 2

4

Quick Revision

  • ✔ Call Stack executes synchronous code.
  • ✔ Promise callbacks go to the Microtask Queue.
  • ✔ setTimeout callbacks go to the Macrotask Queue.
  • ✔ Microtasks execute before Macrotasks.
  • ✔ Event Loop moves tasks only when the Call Stack is empty.
