Section 1 - JavaScript Execution Context

What is Execution Context?

Execution Context is the environment where JavaScript code is executed. Before running your code, JavaScript creates a workspace that contains variables, functions, memory and information about the current execution.

Types of Execution Context

Execution Context ├── Global Execution Context (Created once) ├── Function Execution Context (Created on every function call) └── Eval Execution Context (Rarely used)

Global Execution Context (GEC)

The Global Execution Context is created when the JavaScript file starts executing. Every JavaScript program has exactly one Global Execution Context. 

let name = "Omkar";

function greet() {
    console.log("Hello");
}

greet();
Global Execution Context Memory ------------------------- name -> undefined greet -> function Execution ------------------------- Line 1 Line 2 Line 3

Function Execution Context (FEC)

Every time a function is called, JavaScript creates a new Function Execution Context. Each function call has its own memory and local variables. 

function add(a,b){
   return a+b;
}

add(10,20);
Global Context ↓ add() ↓ Function Execution Context Arguments a = 10 b = 20

Call Stack

Execution Contexts are stored inside the Call Stack using the LIFO (Last In First Out) principle. 

function one(){
   two();
}

function two(){
   three();
}

function three(){
   console.log("Hello");
}

one();
Top three() two() one() Global Bottom

Memory Creation Phase

Before executing code, JavaScript scans the entire program and allocates memory.

   console.log("Hello");

Execution Phase

After memory allocation, JavaScript executes code line by line.

Memory Creation ↓ Execution Starts ↓ Assign Values ↓ Call Functions ↓ Finish

Lexical Environment

Every Execution Context has a Lexical Environment that stores local variables and keeps a reference to the outer environment. 

let company = "OpenAI";

function employee(){
    let name = "Omkar";
    console.log(company);
}

employee();
Global Scope company ↑ employee() name

Scope Chain

If a variable is not found in the current scope, JavaScript searches the parent scope, then grandparent scope until the global scope. 

let country = "India";

function first(){

   let state = "Maharashtra";

   function second(){

      let city = "Mumbai";

      console.log(country);

   }

   second();

}

first();
Global country ↑ first() state ↑ second() city

Execution Flow

JS Starts ↓ Global Execution Context ↓ Memory Creation Phase ↓ Execution Phase ↓ Function Call ↓ New Function Context ↓ Return ↓ End

Interview Questions

  1. What is an Execution Context?
    It is the environment where JavaScript executes code.
  2. How many Global Execution Contexts exist?
    Only one per JavaScript program.
  3. When is a Function Execution Context created?
    Whenever a function is invoked.
  4. What are the two phases?
    Memory Creation Phase and Execution Phase.
  5. What is the Call Stack?
    A LIFO stack that stores active execution contexts.
  6. What is a Lexical Environment?
    It stores variables and references the outer scope.
  7. What is Scope Chain?
    The path JavaScript follows to find a variable.
  8. Why is Execution Context important in React?
    Hooks, closures and event handlers all rely on it.

Summary

  • Execution Context is the workspace where JavaScript runs code.
  • Every program has one Global Execution Context.
  • Every function call creates a new Function Execution Context.
  • JavaScript first allocates memory, then executes code.
  • Lexical Environment and Scope Chain control variable lookup.
  • The Call Stack manages function execution.
