What is Functional Programming?

Functional Programming (FP) means solving problems by composing functions and avoiding unnecessary changes to shared data.

Input → Function → Output Good FP: same input → same output minimal side effects data is not mutated

JavaScript is not a purely functional language, but it supports many FP concepts.

1. Pure Functions

A pure function:

  • Returns the same output for the same input.
  • Does not change outside data.
function add(a, b) {
  return a + b;
}

add(2, 3); // 5

Impure Example

let total = 0;

function addToTotal(value) {
  total += value;
}

The function changes external state, so it is impure.

2. Immutability

Immutability means do not change the existing value; create a new value instead.

// Bad
user.age = 26;

// Good
const updatedUser = {
  ...user,
  age: 26
};

This is especially important in React state management.

3. Higher Order Functions

A Higher Order Function (HOF) either takes a function as an argument or returns a function.

function calculate(a, b, operation) {
  return operation(a, b);
}

calculate(5, 2, (x, y) => x + y); // 7
Function │ ├── accepts function │ └── or returns function

map, filter, reduce, some, every and find are common HOFs.

4. map()

map() transforms every item and returns a new array of the same length.

const nums = [1, 2, 3];

const doubled = nums.map(n => n * 2);

console.log(doubled);
// [2, 4, 6]
[1, 2, 3] ↓ map [2, 4, 6]

Use it when you want to transform every item.

5. reduce()

reduce() combines an array into one accumulated result.

const nums = [1, 2, 3, 4];

const sum = nums.reduce(
  (total, n) => total + n,
  0
);

console.log(sum); // 10
1 + 2 + 3 + 4 ↓ reduce 10

The result can be a number, string, object, array, Map, etc.

6. filter()

filter() keeps items for which the callback returns true.

const nums = [1, 2, 3, 4, 5];

const even = nums.filter(n => n % 2 === 0);

console.log(even);
// [2, 4]
[1,2,3,4,5] ↓ filter [2,4]

Use it when you want a subset of the array.

7. some()

some() checks whether at least one item passes the condition.

const nums = [1, 3, 4];

nums.some(n => n % 2 === 0);
// true

Returns a Boolean.

8. every()

every() checks whether all items pass the condition.

const nums = [2, 4, 6];

nums.every(n => n % 2 === 0);
// true

Returns a Boolean.

9. find()

find() returns the first matching element.

const users = [
  { id: 1, name: "A" },
  { id: 2, name: "B" }
];

const user = users.find(u => u.id === 2);

console.log(user);
// { id: 2, name: "B" }

If nothing matches, it returns undefined.

10. flatMap()

flatMap() maps each item and then flattens the result by one level.

const nums = [1, 2, 3];

const result = nums.flatMap(n => [n, n * 2]);

console.log(result);
// [1,2,2,4,3,6]
map → [[1,2],[2,4],[3,6]] flatMap → [1,2,2,4,3,6]

Method Comparison

map vs forEach

const nums = [1,2,3];

const result = nums.map(n => n * 2);
// [2,4,6]

nums.forEach(n => console.log(n));
// no useful returned array

Use map() when you need the transformed array. Use forEach() for side effects.

React Connection

function UserList({ users }) {
  return (
    <ul>
      {users
        .filter(user => user.active)
        .map(user => (
          <li key={user.id}>{user.name}</li>
        ))}
    </ul>
  );
}

This combines immutability, pure callbacks, filter() and map() — patterns used constantly in React.

Most Asked Interview Questions

  1. What is a pure function? Same input gives same output and it has no unwanted side effects.
  2. What is immutability? Creating new data instead of changing existing data.
  3. What is a Higher Order Function? A function that accepts or returns another function.
  4. What does map return? A new array with one transformed result per original item.
  5. map vs filter? map transforms; filter selects.
  6. What does reduce do? Builds one accumulated result from an array.
  7. some vs every? some needs one match; every needs all matches.
  8. What does find return? The first matching element or undefined.
  9. flatMap vs map? flatMap maps and flattens one level.
  10. Does map mutate the original array? No, assuming the callback itself does not mutate the items.
  11. Why are pure functions useful in React? They make rendering and state updates predictable and easier to test.
  12. Can reduce return an object? Yes; the accumulator can be any value.

Scenario-Based Questions

  1. You need to double every price.
    Use map().
  2. You need only active users.
    Use filter().
  3. You need the total cart value.
    Use reduce().
  4. You need to know whether at least one user is an admin.
    Use some().
  5. You need to verify every form field is valid.
    Use every().
  6. You need the first user with a particular ID.
    Use find().
  7. Each product produces two output values and you want one flat array.
    Use flatMap().
  8. You need to render a list in React.
    Use map() and provide a stable key.
  9. You need to update React state without mutation.
    Create a new object/array with spread, map, filter, or other immutable operations.
  10. You need to log every item but do not need a new array.
    Use forEach(), not map().
  11. You need a reusable function that accepts different operations.
    Use a Higher Order Function by passing the operation as an argument.
  12. You need predictable output for unit testing.
    Prefer pure functions that avoid external state and side effects.

Quick Revision

  • ✔ Pure = predictable + no unwanted side effects.
  • ✔ Immutable = create new data instead of mutating old data.
  • ✔ HOF = accepts or returns a function.
  • ✔ map = transform.
  • ✔ filter = select.
  • ✔ reduce = accumulate.
  • ✔ some = at least one.
  • ✔ every = all.
  • ✔ find = first match.
  • ✔ flatMap = map + flatten one level.
