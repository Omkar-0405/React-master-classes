What is ES6+?

ES6 introduced major JavaScript improvements. ES6+ means ES6 and newer language features.

1. let and const

Both are block-scoped.

let age = 25;
age = 26; // allowed

const name = "Omkar";
// name = "Rahul"; // TypeError
Featureletconst
Block scopedYesYes
ReassignYesNo
RedeclareNoNo
TDZYesYes

Prefer const unless reassignment is required.

2. Template Literal

Backticks allow interpolation and multi-line strings.

const name = "Omkar";
const age = 25;

const message = `My name is ${name} and I am ${age}.`;

3. Optional Chaining (?.)

Safely accesses a property when a value may be null or undefined.

const user = { profile: { name: "Omkar" } };

console.log(user.profile?.name); // Omkar
console.log(user.address?.city); // undefined

user.getName?.();

It avoids errors from missing intermediate properties.

4. Nullish Coalescing (??)

Uses the right side only when the left side is null or undefined.

const name = null;
const result = name ?? "Guest"; // Guest

0 || 10;  // 10
0 ?? 10;  // 0

"" || "Guest"; // Guest
"" ?? "Guest"; // ""

Use ?? when values such as 0 and "" are valid.

5. Modules

Modules split code into separate files using export and import.

// math.js
export const add = (a, b) => a + b;

// app.js
import { add } from "./math.js";

Default export

// User.js
export default function User(){}

// app.js
import User from "./User.js";

Each module has its own scope.

6. Dynamic Import

Loads a module only when it is needed.

button.addEventListener("click", async () => {
  const module = await import("./heavyFeature.js");
  module.start();
});
Initial page ↓ User needs feature ↓ import("./feature.js") ↓ Feature loads

Useful for code splitting and reducing initial JavaScript.

7. Default Parameters

A default value is used when an argument is omitted or undefined.

function greet(name = "Guest") {
  return `Hello ${name}`;
}

greet();        // Hello Guest
greet("Omkar"); // Hello Omkar
greet(undefined); // Hello Guest
greet(null);      // Hello null

Most Asked Interview Questions

  1. let vs const? Both are block scoped; let can be reassigned, const cannot.
  2. Are let and const hoisted? Yes, but they remain in the TDZ until initialized.
  3. What are template literals? Backtick strings supporting interpolation and multi-line text.
  4. What does optional chaining do? Safely accesses properties/calls when a value may be nullish.
  5. What does ?? do? Provides a fallback only for null or undefined.
  6. ?? vs ||? || treats all falsy values as fallback; ?? only null/undefined.
  7. What are modules? Files with their own scope that explicitly import/export values.
  8. Why dynamic import? To load code on demand and support code splitting.
  9. When do default parameters apply? When the argument is omitted or undefined.
  10. Does null trigger a default parameter? No.
  11. Why is ES6+ important for React? Modern React code relies heavily on these features.
  12. Can optional chaining be used with functions? Yes, e.g. obj.method?.().

Scenario-Based Questions

  1. A variable should never be reassigned.
    Use const.
  2. A loop counter changes.
    Use let.
  3. An API field may not exist.
    Use optional chaining.
  4. 0 is valid but a fallback is needed only when missing.
    Use ??, not ||.
  5. An API username may be null.
    Use user.name ?? "Guest".
  6. A large feature is rarely used.
    Consider dynamic import for code splitting.
  7. A utility is shared across files.
    Export it and import it where needed.
  8. A function has an optional argument.
    Give the parameter a default value.
  9. You need readable dynamic UI text.
    Use a template literal.
  10. A component is needed only after a user opens a feature.
    Use dynamic import, often with React lazy loading.
  11. An empty string is a valid value.
    Use ?? instead of ||.
  12. A deeply nested API response may be incomplete.
    Use optional chaining and a nullish fallback where appropriate.
