What is a Promise?

A Promise is an object that represents the future result of an asynchronous operation.

Request starts ↓ Promise / | \ Pending Fulfilled Rejected

1. Promise States

StateMeaning
PendingOperation is running.
FulfilledOperation succeeded.
RejectedOperation failed.
const p = new Promise((resolve, reject) => {
  resolve("Success");
});

A Promise can settle only once.

2. Promise Chaining

Use the result of one asynchronous step in the next step.

fetch("/user")
  .then(res => res.json())
  .then(user => user.name)
  .then(name => console.log(name))
  .catch(error => console.error(error));

Each .then() returns a new Promise, which makes chaining possible.

3. Promise.all()

Use when all operations are required.

Promise.all([fetchUsers(), fetchProducts(), fetchOrders()])
  .then(([users, products, orders]) => console.log(users, products, orders))
  .catch(error => console.error(error));
A ──┐ B ──┼──► Promise.all ──► Success when all fulfill C ──┘ Any rejection → Reject

4. Promise.race()

Returns the first Promise that settles — fulfilled or rejected.

Promise.race([serverA(), serverB()])
  .then(result => console.log(result))
  .catch(error => console.error(error));

Useful for competing requests and timeouts.

5. Promise.allSettled()

Waits for every Promise, whether it succeeds or fails.

Promise.allSettled([
  Promise.resolve("A"),
  Promise.reject("B"),
  Promise.resolve("C")
]).then(results => console.log(results));
[
 { status: "fulfilled", value: "A" },
 { status: "rejected", reason: "B" },
 { status: "fulfilled", value: "C" }
]

6. Promise.any()

Returns the first fulfilled Promise. It keeps waiting through rejections.

Promise.any([serverA(), serverB(), serverC()])
  .then(result => console.log(result))
  .catch(error => console.error(error));

If all Promises reject, it rejects with AggregateError.

7. async / await

async/await is cleaner syntax for working with Promises.

async function getUser(){
  try {
    const response = await fetch("/user");
    const user = await response.json();
    console.log(user);
  } catch(error) {
    console.error(error);
  }
}

await pauses that async function; it does not block the JavaScript thread.

8. Error Handling

Using catch()

fetch("/user")
  .then(res => res.json())
  .catch(error => console.error(error));

Using try/catch

async function load(){
  try {
    const res = await fetch("/user");
    return await res.json();
  } catch(error) {
    console.error(error);
  }
}

Important Comparison

MethodBehavior
Promise.allAll fulfill; one rejection rejects the result.
Promise.raceFirst settled Promise wins.
Promise.allSettledWaits for every Promise.
Promise.anyFirst fulfilled Promise wins.

Most Asked Interview Questions

  1. What is a Promise? An object representing a future asynchronous result.
  2. What are its states? Pending, fulfilled and rejected.
  3. Can a Promise change state twice? No. Once settled, it cannot change again.
  4. What does Promise.all do? Waits for all to fulfill; rejects if one rejects.
  5. What does Promise.race do? Returns the first settled result.
  6. What does Promise.allSettled do? Waits for all and reports every outcome.
  7. What does Promise.any do? Returns the first fulfilled result.
  8. What if Promise.any has all rejections? It rejects with AggregateError.
  9. async/await vs Promise? async/await is syntax built on Promises.
  10. Does await block JavaScript? No; it pauses only the async function.
  11. How are errors handled? With .catch() or try/catch.
  12. Why does .then return a Promise? To allow asynchronous chaining.

Scenario-Based Questions

  1. Three APIs are all required for a dashboard.
    Use Promise.all().
  2. Three servers provide the same data; first successful response is enough.
    Use Promise.any().
  3. Whichever server settles first should win, even if it fails.
    Use Promise.race().
  4. Ten independent uploads: you need every success/failure.
    Use Promise.allSettled().
  5. An API should timeout after a limit.
    Race the API Promise against a timeout Promise.
  6. One independent API fails, but other results are still needed.
    Use Promise.allSettled().
  7. You want readable sequential async code.
    Use async/await with try/catch.
  8. Three independent API calls are written with three sequential awaits.
    Start them first and use Promise.all() if they do not depend on each other.
  9. API B needs an ID returned by API A.
    Use sequential await or Promise chaining.
  10. You want every result even when some tasks fail.
    Use Promise.allSettled().
  11. Only one successful response is required.
    Use Promise.any().
  12. A rejected Promise is not handled.
    Add .catch() or handle it with try/catch around await.
