What is Scope?

Scope defines where a variable can be accessed. Think of it as the visibility area of a variable.

Variable Created │ ▼ Where can it be used? │ ▼ That area is called Scope

1. Global Scope

Variables declared outside all functions or blocks are globally accessible.

let company = "OpenAI";

function show(){
  console.log(company);
}

show();

Output: OpenAI

2. Function Scope

Variables declared inside a function are available only inside that function.

function demo(){
  let name = "Omkar";
  console.log(name);
}
demo();
console.log(name);

Output: ReferenceError

Function --------- name --------- Outside ❌

3. Block Scope

let and const are block scoped.

if(true){
 let age = 24;
}
console.log(age);

Output: ReferenceError

var ignores block scope.

if(true){
 var city="Mumbai";
}
console.log(city);

Output: Mumbai

4. Module Scope

Variables declared in one ES Module are private unless exported.

// math.js
export const PI = 3.14;

// app.js
import { PI } from "./math.js";

Modules prevent global pollution and make code reusable.

Scope Chain

let country="India";

function state(){
  let s="MH";

  function city(){
    console.log(s);
    console.log(country);
  }

  city();
}
city() │ state() │ Global

JavaScript searches the current scope first, then parent scopes until it finds the variable.
