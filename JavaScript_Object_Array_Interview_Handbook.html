Why Objects & Arrays Matter

Objects store related data using keys. Arrays store ordered collections. React uses both everywhere: props, state, API responses and lists.

1. Spread Operator (...)

Spread copies values from an object or array into a new object/array.

const user = { name: "Omkar", age: 25 };
const updated = { ...user, age: 26 };

const a = [1, 2, 3];
const b = [...a, 4];
Original object │ └── spread ... ──► new object

Important: Spread creates a shallow copy.

2. Rest Operator (...)

Rest collects remaining values into one variable.

const [first, ...remaining] = [10, 20, 30, 40];
console.log(first);      // 10
console.log(remaining);  // [20, 30, 40]

function sum(...numbers){
  return numbers.reduce((a,b) => a + b, 0);
}

Same ... syntax, different job: spread expands; rest collects.

3. Destructuring

Destructuring extracts values from objects or arrays into variables.

const user = { name: "Omkar", age: 25 };
const { name, age } = user;

const colors = ["red", "blue"];
const [first, second] = colors;

React Example

function UserCard({ name, age }) {
  return <h2>{name} - {age}</h2>;
}

4. Object.freeze()

Object.freeze() prevents changing, adding or deleting properties at the first level.

const user = Object.freeze({
  name: "Omkar",
  age: 25
});

user.age = 26;    // ignored in non-strict mode
user.city = "Mumbai"; // ignored
delete user.name; // ignored

It is shallow. Nested objects can still change.

const user = Object.freeze({
  profile: { age: 25 }
});

user.profile.age = 26; // can change

5. Object.seal()

seal() prevents adding and deleting properties, but existing properties can be changed.

const user = Object.seal({
  name: "Omkar",
  age: 25
});

user.age = 26;       // allowed
user.city = "Mumbai"; // not allowed
delete user.name;     // not allowed

freeze vs seal

Operationfreeze()seal()
ReadYesYes
Modify existingNoYes
Add propertyNoNo
Delete propertyNoNo

6. Object.assign()

Object.assign() copies enumerable own properties from source objects into a target object.

const user = { name: "Omkar" };
const details = { age: 25 };

const result = Object.assign({}, user, details);

console.log(result);
// { name: "Omkar", age: 25 }

Like spread, it performs a shallow copy.

7. Shallow Clone

A shallow clone copies only the first level. Nested objects still share the same reference.

const original = {
  name: "Omkar",
  address: { city: "Mumbai" }
};

const copy = { ...original };

copy.address.city = "Pune";

console.log(original.address.city);
// Pune
original │ └── address ─────┐ ├── same nested object copy │ └── address ─────┘

8. Deep Clone

A deep clone creates independent copies of nested objects too.

const original = {
  name: "Omkar",
  address: { city: "Mumbai" }
};

const copy = structuredClone(original);

copy.address.city = "Pune";

console.log(original.address.city);
// Mumbai

structuredClone() is generally preferred for supported structured-cloneable data. JSON cloning is limited.

const copy = JSON.parse(JSON.stringify(original));

JSON cloning loses or changes values such as functions, undefined, Dates, Maps and Sets.

Shallow vs Deep Clone

Top-level copyYesYes

React Connection

React state should be updated without mutating the existing object.

setUser(prev => ({
  ...prev,
  age: prev.age + 1
}));

For nested state:

setUser(prev => ({
  ...prev,
  address: {
    ...prev.address,
    city: "Pune"
  }
}));

This creates new references so React can detect the update reliably.

Most Asked Interview Questions

  1. What does spread do? Expands values into a new object or array.
  2. Spread vs rest? Spread expands; rest collects.
  3. What is destructuring? Extracting values into variables.
  4. Is spread a deep clone? No, it is shallow.
  5. freeze vs seal? freeze prevents modifications; seal allows changing existing properties.
  6. Does freeze deep-freeze an object? No, it is shallow.
  7. What does Object.assign do? Copies enumerable own properties into a target object.
  8. What is shallow copy? Top level is copied but nested references are shared.
  9. What is deep copy? Nested data is copied into independent structures.
  10. Best modern deep-clone option? structuredClone() for supported data types.
  11. Why avoid JSON cloning? It does not preserve many JavaScript types.
  12. Why is immutability important in React? New references help React detect state changes and keep updates predictable.

Scenario-Based Questions

  1. You need to update one property without changing the original object.
    Use object spread.
  2. You need to add an item without mutating an array.
    Use [...items, newItem].
  3. You need the first array value and all remaining values.
    Use array destructuring with rest.
  4. You need selected object properties from API data.
    Use object destructuring.
  5. You need to prevent accidental changes to a configuration object.
    Use Object.freeze(); remember it is shallow.
  6. You want properties fixed but values still editable.
    Use Object.seal().
  7. You clone an object with spread, then a nested change affects the original.
    The clone is shallow; clone the nested object too or use structuredClone().
  8. A React nested state update is not written immutably.
    Create new references at every changed nesting level.
  9. You need to merge several flat configuration objects.
    Use spread or Object.assign().
  10. You need a true independent copy of supported nested data.
    Use structuredClone().
  11. You use JSON stringify/parse to clone a Date.
    It becomes a string, so JSON cloning is not appropriate when type preservation matters.
  12. You need a function to accept any number of arguments.
    Use a rest parameter.

Quick Revision

  • ✔ Spread = expand/copy.
  • ✔ Rest = collect.
  • ✔ Destructuring = extract.
  • ✔ freeze = cannot modify/add/delete.
  • ✔ seal = cannot add/delete, but can modify.
  • ✔ assign = shallow property copy.
  • ✔ Spread/assign = shallow.
  • ✔ structuredClone = deep clone for supported data.
  • ✔ React state updates should be immutable.
